# وِرد · Wird

تطبيق آيفون للأوراد اليومية: أذكار الصباح والمساء، سورتا الكهف والملك بصفحات مصحف المدينة، والاستغفار مع الويدجت والعدّ من خارج التطبيق.

- الإصدار: 1.0.0
- تطوير: أحمد الخنبشي
- يتطلب: iOS 17 أو أحدث

## التثبيت
1. من صفحة **Releases** حمّل الملف `Wird-1.0.0-unsigned.ipa`.
2. وقّعه وثبّته بأداة التوقيع التي تستخدمها.

## البناء
يُبنى تلقائياً في GitHub Actions (Xcode 26) عند كل رفع إلى `main`، ويُنشر الملف في Releases مع صور من المحاكي.

- `App/` تطبيق الآيفون (Swift): الواجهة، الجسر، الاهتزاز، المواقيت، التنبيهات، النافذة العائمة، العدّاد على شاشة القفل، النسخ الاحتياطي.
- `App/Web/` الواجهة المعتمدة تعمل بدون إنترنت (تُولَّد بـ `tools/build_web.py` من `tools/wird-prototype.html`).
- `Widget/` الويدجت والعدّاد الحي على شاشة القفل.
- `Shared/` التخزين المشترك واختصار «استغفر».
